# Original specification — optional home workout module

Follow-up to `PROMPT.md`, specifying the optional equipment-free fitness module, unedited.

---

20. OPTIONAL HOME WORKOUT & FITNESS MODULE

I also want NutriTrack AI to include an optional home workout section for days when I want to exercise without going to the gym.

This feature must be completely optional. My primary focus remains nutrition and fat loss. Never force me to complete workouts.

A. Home Workout Dashboard

Create a separate section called “Home Workouts”.

Display:

* Today’s suggested workout.
* Estimated workout duration.
* Difficulty level.
* Target muscle groups.
* Estimated calories burned (clearly labelled as an estimate).
* Weekly workout history.
* Workout completion streak.

Provide three categories:

1. Beginner workouts.
2. Fat-loss and general fitness workouts.
3. Strength and muscle-preservation workouts.

All exercises must be possible without gym equipment, weights or machines.

B. Exercise Library With Pictures

Create an interactive exercise library.

Every exercise must include:

* Exercise name.
* Clear demonstration picture or illustration.
* Starting position.
* Step-by-step instructions.
* Correct body posture.
* Breathing instructions.
* Common mistakes.
* Beginner modifications.
* Safety precautions.
* Target muscles.
* Suggested repetitions and sets.

Use actual exercise demonstration illustrations or short looping animations wherever possible.

Do not use unrelated stock photographs.

Include these exercises:

Upper body

* Wall push-ups.
* Knee push-ups.
* Standard push-ups.
* Incline push-ups using a stable surface.
* Arm circles.
* Plank shoulder taps.

Lower body

* Bodyweight squats.
* Chair squats.
* Reverse lunges.
* Glute bridges.
* Calf raises.
* Wall sits.

Core

* Forearm plank.
* Dead bugs.
* Bird dogs.
* Standing knee raises.
* Modified crunches.

Cardio and general fitness

* Marching in place.
* Step jacks.
* Low-impact jumping jacks.
* High knees (beginner modification).
* Mountain climbers (modified version).

C. Illustrated Exercise Instructions

When I tap an exercise, open a detailed exercise screen.

Show a large demonstration image illustrating the correct movement.

Where useful, show two or three stages:

1. Starting position.
2. Movement execution.
3. Ending position.

Include directional arrows where appropriate.

The illustrations should clearly demonstrate body positioning and movement.

Add a short instructional animation or video when a reliable demonstration is available.

D. Personalised Home Workout Generator

Create a workout generator based on:

* My current fitness level.
* Available time.
* Preferred difficulty.
* Target muscle groups.
* Whether I want a low-impact or regular workout.

Suggested workout durations:

* 5 minutes.
* 10 minutes.
* 15 minutes.
* 20 minutes.
* 30 minutes.

Generate routines that require absolutely no equipment.

Start with beginner-friendly exercises and progressively increase difficulty.

Do not prescribe excessive exercise or unrealistic calorie-burning targets.

E. Workout Session Interface

When I start a workout, show:

* Current exercise.
* Demonstration picture.
* Exercise instructions.
* Set number.
* Repetition counter.
* Rest timer.
* Next exercise.
* Pause button.
* Skip button.
* Finish workout button.

Use a clean, distraction-free interface.

Allow me to manually record completed repetitions.

F. Optional Workout Logging

After completing a workout, ask:

“Would you like to save this workout?”

If I select Yes, record:

* Workout date.
* Start time.
* Duration.
* Exercises performed.
* Sets completed.
* Repetitions.
* Difficulty level.
* Personal notes.
* Perceived effort.

If I select No, do not add it to my workout history.

Allow manual logging of workouts I complete outside the application.

G. AI Workout Feedback

After each logged workout, provide feedback:

* Which muscle groups were trained?
* Was the workout balanced?
* Was the difficulty appropriate?
* What can I improve next time?
* What workout would complement this session?

Provide recovery suggestions and rest days when appropriate.

H. Integration With Nutrition Dashboard

Connect workout records to the existing nutrition dashboard.

However:

* Do not automatically increase my calorie allowance because I exercised.
* Show workout calories separately as estimates.
* Do not subtract estimated workout calories from food intake.
* Keep food intake and exercise expenditure as separate metrics.
* Show whether I completed my optional workout.

I. Weekly Fitness Analytics

Add an optional weekly workout report displaying:

* Number of workouts completed.
* Total workout duration.
* Exercises performed.
* Muscle groups trained.
* Workout consistency.
* Progress in repetitions and sets.

Allow me to compare weekly performance.

J. Safety and Accessibility

* Make all workouts equipment-free.
* Include low-impact alternatives.
* Explain proper posture.
* Warn about exercises that may be unsuitable for certain injuries.
* Encourage stopping if I experience pain, dizziness or unusual discomfort.
* Do not promise spot reduction of belly or chest fat.
* Make workouts suitable for beginners.
* Allow me to skip any exercise.

IMPORTANT: This entire module must remain optional. Nutrition tracking must work perfectly even if I never use the workout feature.

The goal is to give me the option to become more active at home without requiring a gym membership or equipment.
